FieldPalm · iPhone

Support

Praktische Hilfe zu Aufnahme, Prüfung, Berichten, Käufen und lokalen Daten.

Kontakt

Schreiben Sie an fieldpalm@zqforge.com. Nennen Sie Ihr iPhone-Modell, die iOS-Version, die FieldPalm-Version, das erwartete Ergebnis und die Schritte, mit denen sich das Problem reproduzieren lässt. Fügen Sie keine Kundennachweise bei, außer dies ist erforderlich und Sie sind dazu berechtigt.

Erste Schritte

Erstellen Sie einen Auftrag, geben Sie eine eindeutige Auftragsnummer und die Serviceart ein und starten Sie ihn. Wählen Sie unter Aufnahme vor jedem Foto Vorher, Arbeit, Nachher, Problem oder Ausrüstung. Prüfen Sie Gerätedaten, Vorher/Nachher-Zuordnungen, Abschlusstext und Unterschriften, bevor Sie sie bestätigen.

Kamera oder Spracheingabe ist nicht verfügbar

Öffnen Sie iOS-Einstellungen → Apps → FieldPalm und erlauben Sie nur die Berechtigungen, die Sie verwenden möchten. Stellen Sie sicher, dass ausreichend Speicherplatz frei ist. Texteingabe bleibt verfügbar, wenn Mikrofon, Spracherkennung oder unterstützte On-Device-Intelligenz nicht verfügbar sind.

Berichte und Exporte

Erstellen Sie Berichte nach abgeschlossenem Auftragsabschluss. Jede erzeugte Revision bleibt erhalten. Verwenden Sie Teilen nur, wenn Sie das PDF oder Nachweis-ZIP an ein von Ihnen kontrolliertes Ziel senden möchten.

Pro wiederherstellen

Öffnen Sie Einstellungen → Abonnement verwalten → Käufe wiederherstellen und melden Sie sich mit dem Apple Account an, mit dem FieldPalm Pro ursprünglich gekauft wurde. Vorhandene lokale Aufträge werden nicht gelöscht, wenn Pro nicht verfügbar ist.

Lokale Daten

FieldPalm hat kein Konto und keine Cloud-Synchronisierung. Lassen Sie die App installiert und sorgen Sie für eine geeignete Gerätesicherung. Das Löschen eines Auftrags oder das Deinstallieren von FieldPalm kann lokale Daten entfernen; exportierte Dateien müssen separat verwaltet werden.
